# yolo-tod 依赖清单（venv 用法，不使用 conda）
# ===========================================================================
# 装之前请注意：**torch / torchvision 不在这里**，要你先自己装。
# 原因是 PyPI 上的 torch 是 CPU-only 轮子，GPU 版只在 PyTorch 的 CUDA 索引上，
# 而装哪个 CUDA 版本取决于你的显卡和驱动。按你的机器选一条（把 cu128 换成
# 你需要的版本；纯 CPU 就用 .../whl/cpu 或者什么都不加）：
#
#     pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
#
# 不知道选哪个：nvidia-smi 看右上角 "CUDA Version"，或去
# https://pytorch.org/get-started/locally/ 选一下。
#
# 先装 torch，再装本文件：这样 pip 看到 torch 已满足 `ultralytics` 的依赖，
# 就不会去 PyPI 拉一个 CPU 版把它盖掉。
#
# 支持的 Python：3.10 ~ 3.14（torchvision 明确排除 3.14.1，其余 3.14.x 可用）。
# 本仓库实测环境：Python 3.13.13 + torch 2.11.0+cu128 + ultralytics 8.4.60，
# 跑通全部测试（smoke 77 + modules 105 + pose 220 + mav6d 49）。
# ===========================================================================
