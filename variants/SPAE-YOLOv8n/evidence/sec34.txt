3.4. Efficient_UAVDet Head</title><p>Aiming at the problem that the original detection head of YOLOv8n uses ordinary <inline-formula>[M:3 × 3]</inline-formula> convolution, which results in high computational cost for airborne embedded systems, a stem feature enhancement module based on adaptive grouped convolution is designed.</p><p>The standard convolutions located before the regression and classification branches of the original detection head are substituted with channel-adaptive grouped convolution, where the group number <italic>g</italic> is dynamically adjusted according to the input channel count <italic>x</italic> of each individual branch. Here, <italic>x</italic> represents the total channel dimension of the input feature map corresponding to the respective detection head branch. The group number is calculated as follows:</p><disp-formula id="FD10-sensors-26-03424"><label>(10)</label>[M:g = x 16]</disp-formula><p>Based on this grouping, the core operation of the channel-adaptive grouped convolution can be formulated as:</p><disp-formula id="FD11-sensors-26-03424"><label>(11)</label>[M:Y = GroupConv ( X , k = 3 , g ) = Concat Conv ( X i , k = 3 ) i = 1 g]</disp-formula><p>The input feature corresponding to the <italic>i</italic>-th group is denoted by <inline-formula>[M:X i]</inline-formula>, with each group containing <inline-formula>[M:x / g]</inline-formula> channels. When the input and output channel numbers are equal, the parameter count of a single <inline-formula>[M:3 × 3]</inline-formula> grouped convolution is reduced from <inline-formula>[M:9 x 2]</inline-formula> to <inline-formula>[M:9 x 2 / g]</inline-formula>. This achieves a <italic>g</italic>-fold reduction in parameters for each convolutional layer, while two consecutive grouped convolution layers are employed to preserve feature extraction capability and maintain the lightweight property of the detection head.</p><p><xref rid="sensors-26-03424-f003" ref-type="fig">Figure 3</xref> illustrates the principle of grouped convolution. The input feature map is divided into two groups along the channel axis, with each group containing half of the total channels. Each group is independently processed using a convolution kernel of the appropriate size, and the resulting outputs are then concatenated to form the final feature. This strategy lowers the parameter count to <inline-formula>[M:1 / g]</inline-formula> of a standard convolution, where <italic>g</italic> denotes the number of groups. In the detection head of this paper, a channel-adaptive version of grouped convolution is employed. Unlike the schematic example with a fixed group setting of <inline-formula>[M:g = 2]</inline-formula> shown in <xref rid="sensors-26-03424-f003" ref-type="fig">Figure 3</xref>, the number of groups here is dynamically computed according to the input channel count <italic>x</italic> in the detection head branch, using the formula <inline-formula>[M:g = x 16]</inline-formula> (for example, if <inline-formula>[M:x = 32]</inline-formula>, then <inline-formula>[M:g = 2]</inline-formula>). The input features are split into <italic>g</italic> groups, convolved independently, and then concatenated, which not only preserves the lightweight advantage of grouped convolution but also adapts to varying channel scales across the multi-branch structure of the YOLOv8n detection head.</p><fig id="sensors-26-03424-f003" position="float"><?disp-level 3?><label>Figure 3</label><caption><p>Schematic Diagram of Group Convolution’s Basic Operational Logic.</p></caption><alternatives><graphic xmlns:xlink="http://www.w3.org/1999/xlink" content-type="image" xlink:href="sensors-26-03424-g003.jpg"><?cloudpmc-path blobs/7e2a/13258917/d7c541bc607f/sensors-26-03424-g003.jpg?><?cloudpmc-bucket cdn?><?image-server-status LOAD_COMPLETED?><?original-height 1948?><?original-width 3078?><?scaled-height 487?><?scaled-width 769?></graphic><graphic xmlns:xlink="http://www.w3.org/1999/xlink" content-type="thumb" xlink:href="sensors-26-03424-g003.gif"><?cloudpmc-path blobs/7e2a/13258917/cb4415fc4533/sensors-26-03424-g003.gif?><?cloudpmc-bucket cdn?></graphic></alternatives></fig><p><xref rid="sensors-26-03424-f004" ref-type="fig">Figure 4</xref> illustrates the overall design of the stem feature enhancement module, which is implemented with two consecutive layers of <inline-formula>[M:3 × 3]</inline-formula> convolution using identical specifications. By substituting standard convolution with the proposed channel-adaptive grouped convolution, the parameter count of each <inline-formula>[M:3 × 3]</inline-formula> convolutional layer is significantly reduced from <inline-formula>[M:9 x 2]</inline-formula> to <inline-formula>[M:9 x 2 / g]</inline-formula>.
